## Layout

- `src/` — source code
- `tests/` — automated tests
- `docs/` — architecture notes and guides
- `outputs/` — build and run artifacts (ignored)
- `.mise/tasks/` — project tasks

## Common Commands

```bash
mise tasks       # List all tasks
mise run dev     # Start dev workflow
mise run test    # Run tests
mise run check   # Run tidy + test
```
